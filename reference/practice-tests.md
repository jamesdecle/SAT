## Student usage

One row per student per test taken. Add rows as tests are administered; never
assign a student a practice test they've already taken, and never build a
quiz that reuses questions from a test a student has taken or will take (see
CLAUDE.md, "Questions" rule — active questions are excluded from bank.json
exports entirely, so this table is a second check, not the only one).
